# Changelog

## 0.1.0

- Extracted the `editor` skill from [dwmkerr/claude-toolkit](https://github.com/dwmkerr/claude-toolkit) as a standalone project.
- Reviews or edits a file against Dave Kerr's writing style, routed through a second model (GPT via Codex by default).
- Bundles the writing-style references and real-prose calibration samples so the skill is self-contained.
